📋 CONFIGURAÇÃO INICIAL
================================================================================

1. BANCO DE DADOS:
   - Importe o dump SQL fornecido no phpMyAdmin
   - Banco: ecommerce_perifericos

2. ABACATEPAY (Sistema de Pagamentos):
   - Crie uma conta em: https://www.abacatepay.com/
   - Ative o "Dev Mode"
   - Gere uma chave de API
   - Configure em: loja/abacatepay_config.php

3. PHP:
   - Habilite extensões: php_openssl.dll e php_curl.dll
   - Edite o php.ini do EasyPHP
